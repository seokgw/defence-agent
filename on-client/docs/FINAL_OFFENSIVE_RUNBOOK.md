## 핵심 기능 3가지

1. **PC 요약**: CPU 사용률, 메모리 사용량, 작업 디스크 여유 공간과 별도 SDP 상태를 먼저 본다. CPU는 200ms 표본이며 메모리는 GiB와 사용률, 디스크는 GiB 단위다.
2. **읽기 전용 관찰**: 네트워크 구성 개수, 방화벽 세 프로필, Windows System·Application의 최근 경고·오류 집계를 본다. 인터넷 도달성·침해·보안 종합 판정이 아니다. 설정 변경·권한 상승·공격 모의시험은 없다.
3. **측정 비교**: 이 탭에서 받은 실제 응답 중 최대 12회의 시각·CPU·메모리·디스크를 보관하고 직전 대비 %p를 표시한다. 기록은 브라우저 메모리에만 있으며 새로고침·종료 시 사라진다. 과거 기록을 현재 값으로 표시하지 않는다.

조회 전·수집 중·실패·지원 없음·형식 불일치·오래된 값은 텍스트로 구분한다. 60초가 지나면 현재 값 표시를 중단하며 서버를 자동 재조회하지 않는다. 자동 재시도·예시 대입·강제 정상 처리는 없다. 부분 수집이면 항목 수와 확인 불가를 구분한다.

## 실제 실행과 확인 순서

Git 최상위는 `코덱스-agent`, 앱 실행 위치는 그 안의 `on-client`다. 이 PC에서 확인한 위치는 기존 Workbench 프로젝트의 `코덱스-agent\on-client`이며, 다른 위치로 복제했다면 그 복제본의 on-client에서 실행한다. 문서의 경로를 실행 코드에 고정하지 않는다.

```powershell
node --version
npm run check
node .\student\dashboard.test.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

현재 확인 버전은 Node v24.20.0, npm 11.19.0, Windows PowerShell 5.1.26100.9711이다. package.json의 기준은 Node 24.19.0, 제공 도구의 허용 주 버전은 22~24다. 외부 npm 의존성이 없으므로 npm install은 실행하지 않았다.

1. 시작 안내가 나오면 http://127.0.0.1:5189/ 를 연다. 포트 충돌이면 다른 프로그램을 종료하지 말고 제공 -Port 옵션을 사용한다.
2. 「보호 현황」의 학생 상태·알림 영역에서 「코덱스 · 내 PC 관제 대시보드」를 찾는다. 조회 전에는 숫자 대신 확인 불가가 정상이다.
3. 「다시 조회」를 한 번 누른다. 수집 중에는 버튼이 비활성화되고 측정 중 안내가 나온다. 끝나면 local-pc 출처와 측정 시각·수집 항목 수를 읽는다.
4. 키보드로 「다시 조회」에 초점을 두고 Enter를 누른다. 최근 기록과 직전 비교를 확인한다. SDP 미연결을 PC 수집 성공과 섞지 않는다.
5. 60초가 지나면 오래된 값 안내와 현재 숫자 숨김을 확인한다. 과거 비교 기록에는 그 수집 시각이 계속 붙는다. 실패·지원 없음·부분 결과는 성공이나 0으로 표시하지 않는다.
6. 업무 앱·보안 기록 메뉴에서 기존 표시가 유지되는지 본다. 실제 사건·승인·집행을 시연하려고 임의 요청하지 않는다.
7. 전경 실행 종료는 해당 PowerShell 창에서 Ctrl+C다. 이번 자동 작업에서는 공식 -Background 옵션으로 시작하고 안내된 node PID의 프로젝트 경로를 확인한 뒤 해당 프로세스만 종료·재시작했다. 이번 총공세에서 전경 Ctrl+C를 직접 재시험한 것은 아니다.

## 포장 준비가 끝났을 때

현재 `package-app`은 제공됐지만 승인 실행 환경이 없어 아직 포장할 수 없다. 담당자가 설치하는 실행 환경·승인 host를 직접 만들거나 우회하지 않는다. `--app-only-v1`로 바꾸지 않는다. 아이콘도 아직 지정하지 않았으므로 포장 전 실제 사용할 256×256 RGB/RGBA PNG를 정해야 한다.

승인 실행 환경과 유효한 아이콘, 커밋된 작업이 준비되면 제공 `docs/PACKAGE_APP.md`의 명령을 따른다. 출력 폴더는 원본 밖의 아직 없는 경로여야 한다. 현재 없는 패키지·manifest 해시·설치 명령을 생성된 결과처럼 쓰지 않는다.

`--finish-materials`로 한 번에 생성한 finish.commit.raw, finish.archive.tar.gz, app.zip, APP_PACKAGE_MANIFEST.json만 같은 묶음으로 사용한다. runtime.zip은 제출하지 않는다. 실제 앱 화면 증거는 별도로 준비하며 개인정보·비밀값을 넣지 않는다. 최종 제출 버튼은 이번에 누르지 않았다.

## 보존·재실행 제한

공식 업데이트는 제공 파일을 사용자 전용 외부 폴더에 백업했다. 학생 코드·문서·Git 기록은 기존 저장소에 남긴다. 이전 21·22단계 문서는 해당 제출 커밋의 역사 기록이며 현재 앱 실행 안내는 이 문서와 0.2.19 제공 README를 따른다. 기존 인증 설정을 복사·삭제하거나 ACL을 완화하지 않았다. 비교 기록은 영구 저장 기능이 아니므로 학생 데이터 백업으로 간주하지 않는다.
